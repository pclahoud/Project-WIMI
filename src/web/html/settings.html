Microphone

Which microphone WIMI records through. This choice stays on this computer: it names a piece of hardware plugged in here, so it is not carried to your other machines.

Speech model

The model does the recognising, and it is downloaded once rather than shipped with WIMI. A bigger one recognises more technical terms and takes longer to run. Measured on this project's own corpus: small.en-q5_1 recognised 84% of the terms at about half of real time, small.en 85% for two and a half times the download, and base.en 75% for a third of the size. Like the microphone, the choice stays on this computer — the file it names lives here.

Starting…

Changing model keeps the old one, so changing back costs nothing. Remove one when you are sure you are finished with it.

Recognition

Before each recording WIMI gives the recogniser a short piece of prose built from the subjects on the entry you are writing, so it knows to expect those words. It is the difference between hearing a drug or an eponym correctly and getting something that sounds like it. Turn it off only if it is putting words into your transcripts that you did not say.

Related Topics

WIMI can read the explanation you write on an entry and suggest relations between your subjects, such as one condition causing another. Nothing is added until you confirm it.

    Anki Integration

    WIMI reads your Anki collection on this computer through the AnkiConnect add-on, so an entry can show the cards for its question. Anki must be open for WIMI to fetch anything; what was fetched before stays readable when it is closed. Every change here is saved as you make it.

    Connection on this computer

    This setting stays on this computer. A copy of your profile on another computer starts with it off.

    The port the AnkiConnect add-on listens on, 8765 unless you changed it in the add-on's settings. WIMI only ever connects to Anki on this computer.

    Refreshing and display

    When this is off, cards are fetched only when you ask, from the entry or with Sync below.

    One row per card, or one combined row per note. Interval, due date and the memory estimates belong to a single card, so the combined view leaves them out.

    Search templates

    A search template tells WIMI how to find a question's cards in Anki. Write it as an Anki search and put {{qid}} where the question id goes, for example tag:MyDeck::{{qid}}. Each template belongs to one question bank of one exam.

    Card fields shown on an entry

    MCP Server

    Run a local Model Context Protocol (MCP) server so an AI assistant on this computer can read your WIMI data. Any assistant or tool that speaks MCP can connect: a desktop chat app, a code editor, or a front end for a model running on this computer, so nothing has to leave the machine. WIMI favours no provider; the server is read-only.

    Start a server on this computer only (127.0.0.1) when enabled.
